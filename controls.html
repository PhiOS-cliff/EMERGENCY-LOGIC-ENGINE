ELE Controls

Operate the system.

ELE is controlled through explicit commands. The operator activates the Kernel, establishes identity and situation through ELI, enters Emergency Logic for procedural compression, and returns to Source for normal General AI conversation.

Current supported host: OpenAI ChatGPT
Quick Start

Activate the Kernel. Establish the situation.

Pilot Commands

The four controls that move the session.

Activate Kernel

Start the system

Begins the boot process, initializes the ELE workspace, and places the session under Kernel governance.

Enter ELI

Return to orientation

Reopens the interface used to identify the operator, define the situation, expose uncertainty, and prepare the condition for movement.

Enter ELE

Engage Emergency Logic

Directs the session toward procedural compression: condition, ownership, bottlenecks, minimums, and the next valid movement.

Exit ELE / Enter Source

Return to General AI

Leaves Emergency Logic and returns the conversation to broad reasoning, exploration, drafting, and normal discussion.

UNO

Maximum emergency compression.

UNO is a single-shot system for conditions where time is collapsing and consequence is near. Its objective is mitigation, not deliberation.

UNO asks

If maximum emergency measures were applied right now, what is the process?

Single-shot system

UNO does not explore the full field. It compresses the environment toward immediate movement.

Mitigation over deliberation

The system seeks the fastest pathway toward stabilization rather than extending discussion.

Consequence is assumed

Time determines where, when, and how severe the consequence becomes.

Immediate levers

UNO exposes the closest available controls, removes tolerances, and accelerates movement toward mitigation.

UNO is not the default operating mode. It is reserved for conditions where time is of the essence, consequence is imminent, and the operator needs maximum procedural compression.
